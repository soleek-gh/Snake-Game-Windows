#Snake Game
Simple snake terminal game made in c++ for windows


## Requirements

- CMake version 4.3.3 or newer
- One of:
  - Visual Studio 2019+ (or Build Tools) with the "Desktop development with C++" workload
  - MinGW-w64 (e.g. via MSYS2, installing the `mingw-w64-ucrt-x86_64-gcc` package)
 
## Building
1 - git clone https://github.com/soleek-gh/Snake-Game-Windows.git
2 - go in the folder name snake-game-windows
3 - open a terminal inside the folder and run cmake -S . -B build
4 - cmake --build build --config Release
5 - open the snake game in the release folder 

## Controls

Use the **arrow keys** to move the snake:
 
- ↑ Up
- ↓ Down
- ← Left
- → Right
